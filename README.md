# Goblin Gambit Guardians

Quero que você desenvolva um jogo.
Será um jogo por Turno, a onde os personagens atacarão automaticamente sem que o usuário precise selecionar as habilidades.

Personagem: Cada personagem terá 3 habilidades, aonde a 3ª sera uma habilidade suprema que terá um Cowldown maior.
1º pesonagem será um Knight (fique livre para fazer as habilidade dele por enquanto).
2º personagem sera um Mago (fique livre para fazer as habilidade dele por enquanto).
3º personagem sera uma Arqueira (fique livre para fazer as habilidade dele por enquanto).

Inimigos: Sera um grupo de Goblins (fique livre para fazer as habilidade dele por enquanto). e no final tera um boss HOBGOBLIN (fique livre para fazer as habilidade dele por enquanto).

FASES: Quero 3 fases, com alguns Goblins Lanceiros, Goblins Guerreiros e Globins magos. e na 4ª fase tera o BOSS.

Quero que seja possivel selecionar a fase para entrar e batalhar antes de começar.
